# DSC-212-Assignment-Karate-Club-Modularity

Assignment done under the course DSC 212 (Graph Theory and Linear Algebra) under Prof Saptarishi Bej of IISER Thiruvananthapuram. 

In this assignment, we applied concepts of modularity to the famous Karate Club Graph to divide the nodes into communities. It was done by creating a random baseline graph and making sure that the our "guessed" community has maximum intra-community edges and minimum inter-community edges when compared to the random baseline. This computation was done using a parameter we constructed called Modularity Score
